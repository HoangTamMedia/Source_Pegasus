// The 6 x 12 item collection. Read by CPegasusCollection::Load.
//
// Two sections, each closed by its own "end". The "end" is mandatory - the
// MemScript parser has no other way out of its loop, and a missing one shows up
// as the misleading "The file were not configured correctly", which is really a
// 1-second watchdog firing on a loop that never terminated. A section number
// the loader does not know breaks out for the same reason.
//
// Section 0 - one row per set:
//
//   Set        1..6
//   Bonus      percent, paid once every one of the set's 12 slots is filled
//   BonusType  which stat it feeds; these are eItemOption values from
//              GameServer\ItemOption.h, and only the MUL_ ones read as a
//              percent:
//                 87  MUL_DEFENSE_SUCCESS_RATE
//                 90  MUL_MP
//                 91  MUL_HP
//                 94  MUL_PHYSI_DAMAGE
//                 96  MUL_MAGIC_DAMAGE
//                127  MUL_DEFENSE
//              Two sets naming the same stat are added together, not applied
//              one after the other.
//
// Section 1 - one row per pedestal:
//
//   Set        1..6
//   Slot       1..12
//   ItemType   item group: 0 Sword 1 Axe 2 Mace 3 Spear 4 Bow 5 Staff
//                          6 Shield 7 Helm 8 Armor 9 Pants 10 Gloves 11 Boots
//                          12 Wings 13 Misc 14 Potion/Jewel
//   ItemIndex  number inside that group
//   Level      required item level, -1 for any level
//   Rarity     0..3, which of the four pedestal frames the client draws
//
// A pedestal left out of section 1 keeps ItemType -1, which means it can never
// be filled - and so its set can never complete and never pays its bonus. That
// is the safe direction: a typo costs a bonus rather than granting a free one.
//
// The client mirrors this table in source\PegasusCollection.cpp so a pedestal
// can show what it wants before it is filled. Change one and change the other.
//==============================================================================
